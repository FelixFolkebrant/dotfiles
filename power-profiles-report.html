POWER MANAGEMENT REPORT

Practical laptop power profiles

A decision-oriented guide for a modern Linux laptop. Ratings estimate battery-life value: ★★★★★ is usually a major win; ★ is rarely worth changing alone. Apply only controls your hardware exposes.

Live audit (31 July 2026): AMD Ryzen with amd-pstate-epp, an integrated Radeon 680M, and no discrete GPU were detected. Firmware exposes low-power, balanced, and performance platform profiles; power-profiles-daemon changes governor/EPP correctly. The internal Lenovo LEN151WQXGA display exposes 60 Hz and 165 Hz—not 90 Hz—so unsupported custom modes should not be forced.

Recommended defaults

ON BATTERY

Power save

Prioritise runtime. Keep the system responsive for browsing, documents, coding and video.

Use: low panel refresh, conservative CPU policy, iGPU-only if hybrid, adaptive brightness, runtime suspend and radio savings.

Expected trade-off: slower sustained builds/games; possible 60 Hz UI.

DEFAULT

Balanced

The everyday profile. Preserve normal responsiveness and enable savings that have little visible cost.

Use: balanced platform policy, automatic GPU runtime suspend, adaptive refresh/brightness, moderate CPU boost.

Expected trade-off: generally imperceptible outside heavy workloads.

AC / DEMANDING WORK

Performance

For compiling, rendering, gaming, external displays or latency-sensitive tasks.

Use: performance platform policy, full refresh rate, aggressive CPU boost and dGPU only when needed.

Expected trade-off: markedly higher draw and fan noise; use on mains where practical.

Profile recipes

Power save: use these first

  1. Set brightness to the lowest comfortable level and 60 Hz refresh.
  2. Select power-saver platform profile and energy-biased EPP.
  3. Keep a hybrid dGPU fully runtime-suspended; launch GPU workloads only on AC.
  4. Enable Wi-Fi power saving, USB autosuspend and screen/suspend timeouts.
  5. Disable unused Bluetooth, WWAN, keyboard lighting and external displays.

Balanced: the recommended daily baseline

  1. Use balanced platform profile and balance_performance EPP.
  2. Keep adaptive brightness and VRR/dynamic refresh enabled.
  3. Enable safe runtime PM, USB autosuspend and dGPU runtime suspend.
  4. Leave turbo enabled; only cap it if compilation/gaming materially shortens runtime.
  5. Use per-app dGPU offload rather than a system-wide performance mode.

Performance: activate deliberately

Use the performance platform profile, native maximum refresh rate, performance-biased CPU EPP and boost. Enable the dGPU only for workloads that need it. This is the right profile for games, rendering, a sustained compile, or external-display work—but it is normally poor for battery life and should be reverted when the task ends.

What to inspect before changing anything

Run this read-only audit in a terminal, then use its output to decide which rows above are actually available. It deliberately avoids changing settings.

printf '== hardware ==\\n'; lspci -nnk | rg -i 'vga|3d|display|network'
printf '\\n== power profiles ==\\n'; powerprofilesctl list 2>/dev/null || true
printf '\\n== CPU driver / policy ==\\n'; cpupower frequency-info 2>/dev/null || true
printf '\\n== platform profile ==\\n'; cat /sys/firmware/acpi/platform_profile_choices 2>/dev/null || true
printf '\\n== batteries / thresholds ==\\n'; grep -H . /sys/class/power_supply/BAT*/{status,capacity,charge_control_end_threshold} 2>/dev/null || true
printf '\\n== GPU runtime status ==\\n'; grep -H . /sys/bus/pci/devices/*/power/{control,runtime_status} 2>/dev/null || true
printf '\\n== active power tools ==\\n'; systemctl --type=service --all | rg -i 'power-profiles|tlp|auto-cpufreq|tuned|thermald'
printf '\\n== current wakeups / draw (install if absent) ==\\n'; sudo powertop

For a Wayland desktop, use the compositor’s display settings or wlr-randr; for X11, use xrandr --query. Do not run TLP, power-profiles-daemon, auto-cpufreq and tuned as competing policy owners. Pick one primary policy layer; firmware/platform profile support is the best first choice when present.

Bottom line

Highest-return adjustments: brightness and sleep timeout on every laptop; refresh-rate reduction on high-Hz panels; and correctly suspending/avoiding a dGPU on hybrid systems. Best default: balanced platform/EPP policy with runtime PM and automatic graphics savings. Avoid chasing tiny kernel-device tweaks until those big levers are confirmed.
